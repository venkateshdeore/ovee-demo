# Ovee Karwa — Portfolio

A small static portfolio site: plain HTML, CSS and JS, no build step.

Live at **https://venkateshdeore.github.io/ovee-demo/**. It's hosted on GitHub Pages and redeploys automatically on every push to `main`.

## Run locally

```sh
./serve.sh          # serves on http://localhost:8000
./serve.sh 3000     # or pick a port
```

Requires Python 3 (preinstalled on macOS). You can also just open `index.html` directly in a browser.

## Files

- `index.html`: content (about, path, writing, contact)
- `styles.css`: styles, including light and dark themes
- `script.js`: theme toggle, writing filters, scroll reveal

## Sources

The content comes from public profiles: LinkedIn, the [ORF contributor page](https://www.orfonline.org/contributors/ovee-karwa) and [Google Scholar](https://scholar.google.com/citations?user=s7OotkQAAAAJ). Edit `index.html` to update details.
